# HONY — sitio web

Hoy está publicada la **página de expectativa** ("Muy pronto"): `index.html`, un solo archivo con sus estilos.

El sitio completo (secciones Clientes, Asesores, Locales, Marcas, validación de 3 vías, niveles y contacto) está guardado en la rama `sitio-completo` del repositorio. Para volver a publicarlo, lleva su carpeta `site/` a la rama `main`.

Las fotos vienen de Pexels (uso libre). La lista está en `assets/img/sources.txt`; si se edita ese archivo, GitHub las descarga solo (flujo "Descargar fotos"). Créditos en `assets/img/CREDITOS.txt`.
